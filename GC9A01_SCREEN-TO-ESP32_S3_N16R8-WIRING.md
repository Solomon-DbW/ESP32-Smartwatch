| :----------------  | :----------------- |
| VCC                | 3V3                |
| GND                | GND                |
| SCL                | GPIO 12            |
| SDA                | GPIO 11            |
| CS                 | GPIO 10            |
| DC                 | GPIO 9             |
| RST                | GPIO 8             |
